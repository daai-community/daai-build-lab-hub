# DaAI Build Lab

**Learn • Build • Showcase • Connect**

DaAI Build Lab is a 2-week, execution-first collaborative incubator by **DaAI Community** where cross-functional squads of **Data** and **AI** practitioners solve real-world industry case studies and ship portfolio-ready solutions.

---

## How Build Lab Works

1. **Cross-Functional Squads:** Builders are grouped into squads of 5 (**3 Data Track + 2 AI Track**) assigned to a specific industry domain.
2. **Real-World Problem Solving:** Squads receive an uncleaned operational dataset and a stakeholder problem brief with no hand-holding on tools or architecture.
3. **Decentralized Team Ownership:** Each squad's Team Lead creates and owns their team GitHub repository from Day 1, collaborating via branches, pull requests, and documented engineering decisions.
4. **Public Showcase & Verification:** Completed projects that meet the Build Lab quality bar are indexed permanently in this hub, with the **Top 3 solutions** spotlighted across DaAI Community channels.

---

## Core Sprint Rules

* **Mandatory Kickoff Attendance:** Attendance at the live kickoff session is mandatory to confirm squad placement and unlock sprint materials.
* **Document Every Trade-Off:** Every squad must maintain a `DECISION_LOG.md` explaining data cleaning assumptions, model choices, and architectural trade-offs.
* **Zero Leaked Secrets:** Never commit API keys, credentials, or sensitive tokens to any repository. Use `.env` files and `.gitignore`.
* **Reproducible Work:** Every repository must include a clear `README.md`, setup instructions (`requirements.txt` or environment file), and a 3–5 minute video walkthrough of the working solution.
