# DaAI Build Lab

**Learn • Build • Showcase • Connect**

DaAI Build Lab is a 2-week, execution-first collaborative incubator by **DaAI Community** where cross-functional teams of **Data** and **AI** practitioners solve real-world industry case studies and ship portfolio-ready solutions.

---

## How Build Lab Works

1. **Cross-Functional Teams:** Builders are grouped into teams of 5 (**3 Data Track + 2 AI Track**) assigned to a specific industry domain.
2. **Real-World Problem Solving:** Teams receive an uncleaned operational dataset and a stakeholder problem brief, with no hand-holding on tools or architecture.
3. **Decentralized Team Ownership:** Each team's Team Lead creates and owns their team GitHub repository from Day 1, collaborating via branches, pull requests, and documented engineering decisions.
4. **Public Showcase & Verification:** Completed projects that meet the Build Lab quality bar are indexed permanently in this hub, with the **Top 3 solutions** spotlighted across DaAI Community channels.

---

## Core Sprint Rules

* **Mandatory Kickoff Attendance:** Attendance at the live kickoff session is mandatory to confirm team placement and unlock sprint materials.
* **Document Every Trade-Off:** Every team must maintain a `DECISION_LOG.md` explaining data cleaning assumptions, model choices, and architectural trade-offs.
* **Zero Leaked Secrets:** Never commit API keys, credentials, or sensitive tokens to any repository. Use `.env` files and `.gitignore`.
* **Reproducible & Accessible Work:** Every submission must include a clear `README.md`, setup instructions (`requirements.txt` or environment file), a live accessible working solution (such as a deployed interactive dashboard, web app, or hosted prototype users can test directly), and a 3 to 5 minute video walkthrough of the solution.
